# Solo macOS 26, niente fallback per macOS 15

Il brief chiedeva macOS 15+ con le API di macOS 26 dove disponibili. Abbiamo scelto macOS 26 come target minimo: Liquid Glass, SpeechAnalyzer e Metal 4 sono centrali per il look e la voce, e mantenere un secondo percorso per ciascuno avrebbe raddoppiato il codice di vetro e voce per un pubblico (l'autore, early adopter) che è già su macOS 26.
